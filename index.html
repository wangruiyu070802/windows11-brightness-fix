排查指南 · Windows 11

亮度调不了？按这个顺序自查

滑块能拖、屏幕不动、Fn 键失效，但设备管理器一切正常。不绑定机型，每一步都写明命令会做什么、执行后会发生什么。

先看结论：同样是「屏幕没反应」，值写没写进驱动，后面的方向完全相反。第一步先把这两件事分开，能省掉一大半排查。

先确认你属于这种情况

  • 设置 → 系统 → 显示 里的亮度滑块能拖动
  • 拖动时屏幕亮度没有任何变化
  • 设备管理器里显卡显示「工作正常」，没有黄色感叹号

三条都符合再往下看。不符合的话直接跳到还是不行？。

命令标记

标记含义能否撤销
只读只查询，不改任何设置不需要
会改亮度会立刻改变当前屏幕亮度用同样命令设回去
会装驱动安装一个驱动包，需要管理员可用 pnputil 卸载

跑「会改亮度」的命令之前，先记住当前亮度，后面好设回去。

第 1 步：亮度接口存不存在

01

只读

Get-CimInstance -Namespace root/wmi -ClassName WmiMonitorBrightness
执行后会发生什么：只读取信息，不改变任何东西。

预期输出类似：

Active            : True
CurrentBrightness : 60
InstanceName      : DISPLAY\XXX0000\...
Levels            : 101
有输出，Levels 约 101接口正常 → 第 2 步
报错或没有输出驱动没暴露接口 → 看「接口都不存在」

第 2 步：写一次，看值有没有到驱动

02

会改亮度

$m = Get-CimInstance -Namespace root/wmi -ClassName WmiMonitorBrightnessMethods
Invoke-CimMethod -InputObject $m -MethodName WmiSetBrightness `
  -Arguments @{Timeout=1; Brightness=20}
执行后会发生什么：屏幕亮度立刻变成 20%（如果一切正常）。不重启，不改注册表，不改电源方案。

读回来验证：

(Get-CimInstance -Namespace root/wmi -ClassName WmiMonitorBrightness).CurrentBrightness
读回 20，屏幕也变暗了亮度控制是好的 → 问题在别处
读回 20，屏幕没变值到了驱动，没到面板 → 第 3 步
读回还是原来的值值没写进去 → 查权限和驱动状态

第 3 步：确认控制的是不是内置屏

03

只读

(Get-CimInstance -Namespace root/wmi -ClassName WmiMonitorBrightness).InstanceName
Get-PnpDevice -Class Monitor | Select-Object Status, FriendlyName
执行后会发生什么：只列出信息。多屏的用户先拔掉外接屏，再回到第 2 步重试。

Windows 的亮度滑块绑定在显示路径上。如果它控制的是不支持 DDC/CI 的外接屏，表现和本文一模一样。这一步必须先排除。

第 4 步：OEM 扩展驱动还在不在

04

只读

pnputil /enum-drivers
执行后会发生什么：列出所有已安装的驱动包，不修改任何东西。

输出很长，重点找 Class Name: Extension、Provider 是显卡厂商的那几条。Intel 的扩展包通常叫 iigd_ext.inf，发布名是 oemNN.inf。

找不到 Intel 的 Extension 包扩展缺失，很可能就是它 → 第 5 步
有 Extension 包可能不是这个原因 → 看「还是不行？」
不确定用第 5 步反查更准

第 5 步：Windows Update 里有没有可装的扩展

05

只读

$session  = New-Object -ComObject Microsoft.Update.Session
$searcher = $session.CreateUpdateSearcher()
$result   = $searcher.Search("IsInstalled=0 and Type='Driver'")
foreach ($u in $result.Updates) {
    "[{0}] {1}" -f $u.DriverClass, $u.Title
    "    HWID: {0}" -f $u.DriverHardwareID
}
执行后会发生什么：只查询可用的驱动更新，不下载，不安装。

再拿到显卡的硬件 ID，用来对号：

Get-CimInstance Win32_VideoController | Select-Object Name, PNPDeviceID

找 [Extension] 开头、并且 HWID 是显卡 PNPDeviceID 前缀的那一条（忽略大小写）。找到就进第 6 步。

第 6 步：装回来

06

会装驱动

图形界面：设置 → Windows 更新 → 高级选项 → 可选更新 → 驱动程序更新 → 勾选那条 Extension → 安装。

命令行（管理员 PowerShell）：

powershell -ExecutionPolicy Bypass -File .\scripts\fix-install-extension.ps1
执行后会发生什么：从 Windows Update 下载那个驱动包并安装，可能提示重启。脚本会先把找到的包名、类别、硬件 ID 打印出来，输入 Y 才会继续。

装完回到第 2 步验证。如果要撤销：

pnputil /enum-drivers | Select-String -Pattern 'iigd_ext' -Context 0,6
pnputil /delete-driver oemNN.inf /uninstall

把 oemNN.inf 换成查到的发布名。

原理

显卡驱动的安装包在升级主驱动时，会清理同一设备上的旧驱动包。OEM 提供的 Extension 扩展驱动和主驱动类 GUID 不同，但共用同一个 oemNN.inf 槽位。主驱动占了槽位，扩展被一起删掉，而新驱动不会主动装回来。

主驱动是通用版本：能识别面板，能接受亮度数值，但不包含 OEM 针对具体面板写的背光适配参数。于是出现这种状态：

拖动滑块 → Windows 写入亮度值 → 显卡驱动接受并记录 → 值停在这里，没送到面板

Fn 快捷键走同一条底层路径，所以一起失效。设备管理器看不出问题，因为驱动本身没坏，缺的是一块配套的拼图。

还是不行？

接口都不存在

第 1 步没有输出，说明显卡驱动没暴露亮度接口。

  1. 设备管理器 → 显示适配器，看是不是「Microsoft 基本显示适配器」。是的话驱动根本没装上。
  2. 重装厂商官网的显卡驱动，不要用第三方驱动工具。
  3. 装完重启，再跑第 1 步。

值写不进去

第 2 步读回的值没变。检查当前 PowerShell 是否以正常用户运行，是否有组策略或管理软件限制了显示设置，或者重启后重试。

值写进去了，屏幕也不动，但不是扩展驱动

  • 自适应亮度：设置 → 系统 → 显示，关掉「当光线变化时自动更改亮度」。
  • 内容自适应亮度：部分 Intel 机器在电池模式下会按画面内容调亮度，让手动调节看起来没效果。注册表 HKLM\SYSTEM\CurrentControlSet\Control\GraphicsDrivers 下的 CABCOption 改成 0 可关闭。
  • 厂商电源管理软件：某些管家类软件会接管亮度，退出后再试。
  • 驱动版本本身有问题：退回上一版，或装厂商官网的 OEM 版。
  • 屏幕硬件问题：外接显示器正常、内置屏在任何系统下都不能调，考虑排线或背光故障。

外接显示器不能调

这是正常的。Windows 只能通过 DDC/CI 控制支持该协议的外接屏，很多显示器不支持，或者需要在显示器菜单里手动开启。

  • 在 Windows 11 + Intel 核显的笔记本上验证过
  • AMD、NVIDIA 平台原理类似，但命令和注册表位置不同，不要直接套用
  • 安装扩展驱动属于系统级改动，建议先创建还原点

English Summary

Symptom. The Windows 11 brightness slider moves but the screen never changes; Fn brightness keys fail too.

How to locate it. Write a brightness value through WmiSetBrightness, read it back, and compare with what the screen does. If the value changes but the panel does not, the fault sits between the driver and the panel. Then check whether an OEM Extension driver is installed and whether Windows Update offers a matching one.

Fix. Reinstall that Extension driver from Windows Update → Advanced options → Optional updates → Driver updates.
